# Petstore Automation (BDD + Selenium + Java)

This project automates the OctoPerf Petstore application:

Application: https://petstore.octoperf.com/actions/Catalog.action

**Automated scenarios**
1. Opening the JPetStore website

2. Registering a new user with unique credentials

3. Logging in with the newly created account

4. Navigating to the FISH category

5. Selecting a product, choosing an item, and adding it to the shopping cart

6. Verifying the cart contents

## Prerequisites
- Java 11+ installed
- Maven installed
- Chrome browser installed (for local runs)
- Recommended IDE: Eclipse / IntelliJ

## Structure
- `pom.xml` - Maven configuration
- `src/test/resources/features` - Cucumber feature files
- `src/test/java` - Step definitions and test runner
- `.github/workflows/ci.yml` - GitHub Actions workflow (CI) (optional)

## How to run locally (Eclipse)
1. Import the project as **Maven > Existing Maven Projects**.
2. Run tests with Maven:
   ```bash
   mvn test
   ```
   The runner uses WebDriverManager to download the ChromeDriver automatically.
3. Reports:
   - Cucumber will produce console output.
   - An HTML report will be generated by Cucumber at `target/cucumber-html-report` (if the plugin is available); the cucumber JSON is at `target/cucumber.json`.

## GitHub Actions CI
A simple workflow file is included at `.github/workflows/ci.yml`. And executes `mvn test` headlessly.
